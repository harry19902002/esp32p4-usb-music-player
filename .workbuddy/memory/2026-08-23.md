## USB Host 读取 U 盘成功 (FAT32)

### 完成内容
- 实现 USB Host + MSC 挂载 U 盘 + 扫描 WAV 文件 (`main/main.c`)
- 依赖组件: `usb_host_msc ^1.1.4` (通过 `main/idf_component.yml` 声明, IDF Component Manager 自动拉取到 managed_components/)
- 编译烧录成功，验证 U 盘读取正常:
  - 检测到金士顿 U 盘 (VID 0x0951), 容量 14755 MB, 扇区 512
  - FATFS 挂载到 /usb0 成功
  - 扫描到 1 个 WAV 文件

### 关键经验 (重要!)
1. **ESP-IDF v6.2 的 FATFS 不支持 exFAT** (`ffconf.h` 里 `FF_FS_EXFAT 0` 硬编码, 无 Kconfig 开关)
   - exFAT 格式 U 盘会导致 `msc_host_vfs_register` 失败 (f_mount 返回非 FR_OK)
   - **必须用 FAT32 格式的 U 盘**
2. **FATFS 扇区要配 512**: `CONFIG_FATFS_SECTOR_512=y` (默认 4096 会导致普通 U 盘挂载失败)
3. **P4 需要 PSRAM 配 USB DMA**: `CONFIG_SPIRAM=y` + `CONFIG_SPIRAM_MODE_HEX=y` + `CONFIG_SPIRAM_SPEED_200M=y` + `CONFIG_USB_HOST_DWC_DMA_CAP_MEMORY_IN_PSRAM=y` (需要 `CONFIG_IDF_EXPERIMENTAL_FEATURES=y`)
4. **ccache .cdep 权限错误**: 编译中途中断后 build 目录会损坏, 报 `Permission denied` 创建 .cdep 失败。解决: 删 build 目录重新编译
5. **串口抓日志**: DTR/RTS 复位 + ReadByte 方式可靠 (capture_usb5.ps1); ReadLine 方式可能拿不到数据
