### 关键环境知识
1. **ESP-IDF v6.2 在 Git Bash 下无法直接使用**（export.sh 路径转换 bug，export.bat 拒绝 MSYSTEM）
   - 必须用 PowerShell 跑：`build_esp32.ps1`（先 `& $env:IDF_PATH\export.ps1` 再 idf.py）
   - 需设置 `$env:PYTHONUTF8 = "1"` 避免中文乱码
   - cmd.exe 被 WorkBuddy 安全策略禁止调用
2. **esp-idf 子模块**：之前用 git submodule update 拉取时，后台任务被 kill 留下僵尸 git 进程占用 index.lock，
   且多个子模块 checkout 不完整（文件缺失）。解决：杀掉残留 git 进程 + `git checkout -- .` 恢复。
   网络不稳时 git 会自动 fallback 到 gitee.com/esp-submodules 镜像。
3. **IDF v6 与 v5 API 差异**：`esp_chip_info_t` 没有 `size` 字段（v6 移除），用 `esp_flash_get_size()` 替代
4. **P4 控制台 UART**：默认 GPIO37(TX)/GPIO38(RX) = CH343P = COM3（默认配置即可）
5. **串口捕获日志**：用 PowerShell SerialPort 读取，先 DTR/RTS 复位再读 10 秒（capture_boot2.ps1 可用）
6. **flash 大小警告**：实际 16MB 但镜像头写 2MB，后续应在 sdkconfig.defaults 加 `CONFIG_ESPTOOLPY_FLASHSIZE_16MB`
